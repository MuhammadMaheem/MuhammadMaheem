## 🐝 Flagship project · Autonomous Research Agent Swarm

> **In plain words:** you ask a question, several AI helpers research different parts of it at the same time, a writer combines what they found, and a reviewer checks every claim. If the answer isn't good enough, it goes back for another round.

```mermaid
flowchart TD
    Q([❓ research question]) --> P[🧠 Planner<br/><sub>Groq LLM → task DAG</sub>]
    P --> S{{⚡ Scheduler<br/><sub>parallel waves via Send</sub>}}
    S --> W[🌐 Web specialist]
    S --> C[🧪 Code specialist<br/><sub>sandboxed</sub>]
    S --> R[📚 RAG specialist<br/><sub>BM25</sub>]
    W & C & R --> Y[✍️ Synthesizer<br/><sub>cited report</sub>]
    Y --> K[🔎 Citation checker<br/><sub>sentence-level audit</sub>]
    K --> X{🎯 Critic}
    X -- "coverage < 0.75<br/>(max 2 loops)" --> P
    X -- "coverage ≥ 0.75" --> F([📄 verified report])

    classDef agent fill:#161b22,stroke:#58a6ff,color:#e6edf3
    classDef gate fill:#161b22,stroke:#f0883e,color:#e6edf3
    classDef io fill:#0d1117,stroke:#3fb950,color:#e6edf3
    class P,W,C,R,Y,K agent
    class S,X gate
    class Q,F io
```

<sub><b>Under the hood:</b> LangGraph state machine with persistence and loops · FastAPI streaming every step over SSE · Next.js + React Flow live DAG · SQLite event store · eval harness comparing the full swarm against a no-critic ablation and a single-agent baseline.</sub>
